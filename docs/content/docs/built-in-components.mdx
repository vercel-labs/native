---
title: "Built-in Components"
---

Browse the [component catalog](/docs/components) for Native markup examples, rendered previews, Zig builder equivalents, and attribute references. For layout and bindings, see [Native UI](/docs/native-ui).

Zig code can inspect the catalog through `native_sdk.canvas.builtin_component_kinds` and `builtin_component_names`. Each descriptor includes its style, root widget kind, semantic role, and composite flag. `builtinComponentWidget(...)` constructs a component’s default widget.
