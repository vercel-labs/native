Use `panel` for a surface with a background, border, and radius. Its children stack over one another; `gap` is rejected. Put a row or column inside to arrange content. Bind `on-press` to make the surface pressable. See [Native UI](/docs/native-ui) for color tokens.

<ComponentPreview name="panel" alt="A panel rendered by the engine" />

## Markup

```html
<panel width="340" padding="16">
  <column gap="6">
    <text>Build output</text>
    <text wrap="true" foreground="text_muted">Build completed.</text>
  </column>
</panel>
```

## Programmatic construction (Zig)

In a Zig view, the `canvas.Ui` builder constructs the same tree programmatically:

```zig
ui.panel(.{ .width = 340, .padding = 16 }, .{
    ui.column(.{ .gap = 6 }, .{
        ui.text(.{}, "Build output"),
        ui.text(.{ .wrap = true, .style_tokens = .{ .foreground = .text_muted } }, "Build completed."),
    }),
})
```
