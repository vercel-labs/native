Use `textarea` for multiline text entry. Bind `text` and `placeholder` to the model and handle `on-input` with the [input](/docs/components/input) edit reducer. Set `width` and `height`, or `grow`, to size it.

Enter and Shift+Enter insert newlines by default. With `on-submit`, Command+Enter on macOS or Ctrl+Enter elsewhere submits. Set `submit-on-enter="true"` for plain Enter to submit while Shift+Enter still inserts a newline. The primary modifier shortcut continues to submit.

Editing shortcuts follow [input](/docs/components/input#editing-keys). On macOS, Command+Backspace deletes the selection or text from the caret to the beginning of the logical line. Soft wrapping does not change that boundary.

## Markup

```html
<textarea width="320" height="96" placeholder="Write a release note" text="{draft}" on-input="draft_edited" />
```

## Programmatic construction (Zig)

In a Zig view, the `canvas.Ui` builder constructs the same tree programmatically:

```zig
ui.el(.textarea, .{
    .width = 320,
    .height = 96,
    .placeholder = "Write a release note",
    .text = model.draft,
    .on_input = Ui.inputMsg(.draft_edited),
}, .{})
```
