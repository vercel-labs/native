---
title: "Package Distribution"
---

The Native SDK is distributed as a Zig codebase plus npm packages for the CLI. The former primitive modules (`geometry`, `assets`, `app_dirs`, `trace`, `app_manifest`, `diagnostics`, and `platform_info`) are now internal Native SDK modules and are available through the main `native_sdk` import instead of standalone Zig packages.

## Install

```bash
npm install -g @native-sdk/cli
```

See the [Quick Start](/docs/quick-start) for the full flow.

## How the npm install works

`@native-sdk/cli` installs the `native` command. Platform-specific optional dependencies supply the prebuilt CLI binary. The package also declares the TypeScript checker and scriptc compiler dependencies used to build TypeScript apps.

The CLI package includes the SDK source and resolves it from its install location. Set `NATIVE_SDK_PATH` to build against a checkout. Offline builds require the compiler dependencies, Zig toolchain, and any app dependencies to be installed already.

The CLI can also download the pinned Zig toolchain: on first `native dev|build|test`, the CLI uses a compatible `zig` from your PATH or offers to download the pinned version into `~/.native/toolchains/` (checksum-verified).

All packages share one version, and the binary packages are pinned exactly, so a given `@native-sdk/cli` version always runs the binary built from the same commit.
