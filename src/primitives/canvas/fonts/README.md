# Bundled fonts

Geist Regular, Medium and Bold are unmodified static TrueType files from
[Geist 1.4.2](https://github.com/vercel/geist-font/tree/4d655731f83507f0258ce5541c297b6553d5d081/packages/next/dist/fonts/geist-sans),
distributed under the [SIL Open Font License](./OFL.txt).

The software renderer and deterministic text measurement use the same face
for each built-in weight. Italic styles use upright outlines at the requested
weight; platform text providers can supply italic faces.
