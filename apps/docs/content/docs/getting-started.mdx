This guide installs Native SDK, builds a small app, and checks its output. You need Node.js 24 or later, and the tools the native host links with on your platform.

## Install the prerequisites

Check that Node.js 24 or later is available:

```console
$ node --version
```

On macOS, install the Xcode command line tools:

```console
$ xcode-select --install
```

On Linux, install the host's libraries and a C compiler, which [Shipping a Linux app](https://github.com/vercel-labs/native/blob/next/packages/cli/docs/linux.md) lists. On Windows, put `zig` on the `PATH`.

## Create a project and install Native SDK

Create a directory for the app and install the CLI into it:

```console
$ mkdir hello
$ cd hello
$ npm init -y
$ npm install -D @native-sdk/cli
```

Add `dev` and `build` scripts that run the CLI:

```console
$ npm pkg set scripts.dev="native dev" scripts.build="native build"
```

The project's package.json now has:

```json
{
  "scripts": {
    "dev": "native dev",
    "build": "native build"
  }
}
```

Both commands work on the project directory. A command you run once, such as `check`, runs as `npx @native-sdk/cli <command>`.

## Create an app

An app is an HTML page with its stylesheets and scripts. Add three files to the `hello` directory.

`index.html`:

```html
<!doctype html>
<html>
  <head>
    <title>Hello</title>
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    <h1 id="greeting">Hello</h1>
    <button id="wave">Wave</button>
    <script type="module" src="app.ts"></script>
  </body>
</html>
```

`style.css`:

```css
body { font-size: 18px; }
h1 { color: #4338ca; }
```

`app.ts`:

```ts
const greeting = document.getElementById("greeting")!;
document.getElementById("wave")!.addEventListener("click", () => {
  greeting.textContent = "Hello, native";
});
```

## Build and run

Build the app:

```console
$ npm run build
$ ./hello
```

The build writes a self-contained app bundle named after the project directory — `hello.app` on
macOS, with the app's files in its Resources, or `hello` with a `hello.resources` directory
elsewhere — so the app keeps working when it is moved and the source is deleted. `./hello` runs it
either way. The window shows a heading and a button. Click **Wave** to change the heading to "Hello, native".

`npx @native-sdk/cli run` builds and runs in one step, and `npm run dev` keeps the window open
while you edit (see [live editing](/guides/live-editing)).

## Check what the app uses

`native check` reports diagnostics without building an executable:

```console
$ npx @native-sdk/cli check
```

Native SDK supports a subset of HTML, CSS and the DOM. The command lists anything the app uses that isn't supported. The [supported features](/reference/supported-html) pages describe what compiles today.

## Run the app headlessly

Apps can run without a window, driven by scripted input, and save a screenshot:

```console
$ NATIVE_STEPS='click #wave | print #greeting' NATIVE_SNAPSHOT=out.png ./hello
Hello, native
```

The run prints the text of `#greeting` after the click and writes `out.png`. The [headless testing guide](/guides/headless-testing) covers every step and environment variable.
