# Menu Desk

A TypeScript and Native markup app with independent model-derived menu-bar items.
Reorder, hide, remove and restore items, change their presentation and menu routes,
and share the same count between the native menus and the app window.

Run `native dev` on macOS. Run `native test` for complete native snapshots,
tray-row routing, recorded effects and replay. The opt-in compiled framework
path is available with `-Dtypescript-view=true`.
