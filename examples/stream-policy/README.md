# Stream Desk

A TypeScript and Native markup app for following process output and streamed HTTP responses. Start a process, collect its output, cancel a live source, or run independent processes. The response button reads a local development endpoint at `http://127.0.0.1:18437/lines`.

Run `native dev` for the native reference view, or `native dev -Dtypescript-view=true` for compiled TypeScript views and stream policy. `native test` drives complete stream records, duplicate admission, data loss, terminal routing, slot reuse, and replay.
